# Azure SQL Scripts

SQL scripts used to create the transactions table,
validate the loaded data and analyse fraud patterns.

- `01_create_tables.sql`: Table creation.
- `02_validate_load.sql`: Row counts, amount totals and null checks.
- `03_fraud_analysis.sql`: Fraud analysis queries.
- `04_risk_analysis` : Risk analysis queries.

These scripts use Azure SQL (T-SQL).
